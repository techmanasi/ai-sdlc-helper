Light and dark
Light, Dark or System in the top bar on every screen; the choice is kept per browser. One layout, colours as tokens: ground, panel, line, text, muted, and the four states (running, waiting, failed, done) plus Future. Every text and state colour passes 4.5:1 in both themes; states also differ by glyph (● ⏸ ✘ ✔), not colour alone.
